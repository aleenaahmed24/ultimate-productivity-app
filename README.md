# Summit — Your All-In-One Productivity System

A focused, gamified productivity workspace: brain dump, today's priorities,
categorized tasks, habit tracking, and a points-and-rewards system to keep
you motivated. Everything is stored locally in your browser — no account,
no server.

## Features

- **Brain Dump** — capture whatever's on your mind with zero friction, then
  turn any item into a real task when you're ready.
- **Today's Priorities** — pick your top few focus items for the day; completing
  one earns bonus points.
- **Tasks** — full CRUD with categories, priority levels, due dates, search,
  and status filters.
- **Habit Tracker** — daily habits with a 7-day grid, streak tracking, and
  streak bonuses.
- **Rewards** — earn points for completing tasks and habits, level up, unlock
  badges, and redeem points for custom rewards you define.
- **Appearance** — 8 color schemes, 6 fonts, and light/dark mode, all
  applied instantly via CSS variables.

## Stack

React + TypeScript + Vite, Tailwind CSS v4, Zustand (with localStorage
persistence), Framer Motion, canvas-confetti, and lucide-react.
